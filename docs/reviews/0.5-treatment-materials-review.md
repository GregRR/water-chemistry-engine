## Finding and adjudication

### F1 — Medium — active-mass instruction caveat lacked code locality

**Confirmed and remediated.** `OptimizerMaterialAddition.preparation_text`
correctly reports physical measured material mass and resolved active chemical
mass. The consumer guide and design document correctly direct optimizer
consumers to that property. However, the generic
`TreatmentPreparationInstruction` and `WaterPreparationInstructions` docstrings
did not locally state that their treatment quantities describe the active
chemical additions replayed by the forward calculator. A consumer discovering
the nested API through code could therefore miss the measured-versus-active
distinction.

The generic instruction class, its `text` property, and the containing
instruction collection now state that they describe active chemical mass and
direct optimizer consumers to `OptimizerMaterialAddition` for physical dosing.
This is a documentation placement correction; no calculation or runtime
behavior changed.

No new defect was found.
