# Water Chemistry Project Structure

The canonical repository/package layout is maintained in
[`PROJECT_STRUCTURE.md`](PROJECT_STRUCTURE.md).

Water-chemistry domain boundaries, calculation contracts, and the current
engine architecture are maintained in
[`WATER_CHEM_DESIGN.md`](WATER_CHEM_DESIGN.md).

This file is intentionally kept as a compatibility pointer rather than a second
copy of the repository tree. Maintaining two independent structure listings led
to stale package paths and planned directories being presented as current
implementation.
